# Employment_Productivity_Analysis
Employee Productivity Analysis using Microsoft Excel

## Project Overview

This project analyzes employee performance and productivity using Microsoft Excel. The analysis focuses on employee performance, productivity, satisfaction, salary, workload, and departmental trends to generate useful insights for HR and workforce decision-making.

## Project Objective

The objective of this project is to analyze employee performance and productivity data and understand patterns related to performance, satisfaction, salary, workload, and department-level trends using Excel.

## Dataset

The dataset contains 1,000 employee records with information related to:

- Employee ID
- Department
- Job Title
- Age
- Years at Company
- Monthly Salary
- Work Hours per Week
- Projects Handled
- Overtime Hours
- Training Hours
- Employee Satisfaction
- Performance Score
- Performance Level
- Productivity Index

## Business Questions

The project addresses several HR and workforce-related questions, including:

1. What is the total number of employees?
2. What is the average performance score?
3. What are the highest and lowest performance scores?
4. How many employees are working in each department?
5. What is the average performance of each department?
6. What is the total salary expense for each department?
7. How many employees satisfy multiple conditions such as high performance and high satisfaction?
8. What is the average performance of employees meeting multiple conditions?
9. How can HR retrieve employee details such as department, salary, and performance score using Employee ID?
10. How can the average performance of a particular department be identified?
11. Which department has the highest average performance?
12. How can department performance be visually compared?
13. How can a department selection dropdown be created?
14. How can high and low performers be highlighted automatically?
15. How can top-performing employees be identified?
16. How can employees with more than 5 years of experience and more than 40 working hours per week be identified?

## Key Outcomes

The project demonstrates how Microsoft Excel can be used to analyze employee performance and productivity, compare departmental trends, identify high and low performers, analyze salary and workload-related information, and answer practical HR business questions.

## Conclusion

This project demonstrates the application of Microsoft Excel for practical employee performance and productivity analysis. By using formulas, lookup functions, Pivot Tables, charts, data validation, conditional formatting, sorting, filtering, and advanced filtering, the project converts employee data into meaningful information that can support HR and workforce analysis.
